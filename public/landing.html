Cara kerja

Dari install sampai scan pertama: 3 langkah.

Tidak perlu kabel OTG, dongle, atau setting rumit. Selama laptop dan HP satu WiFi/LAN yang sama, beres.

Langkah 1

Install di laptop

Jalankan ScanKilat di Windows, izinkan aturan firewall saat diminta, lalu buka dashboard di https://localhost:3443.

⏱ ± 1 menit•Windows 10/11
Langkah 2

Scan QR dari HP

Di dashboard klik Pair HP, arahkan kamera HP ke QR. Kode sesi 6 digit + join key menghubungkan otomatis.

📶 Satu WiFi / LAN•Tanpa install tambahan*
Langkah 3

Scan barcode, otomatis terketik

Klik kolom di Excel/kasir, arahkan HP ke barcode. Dengar beep — kode sudah terketik + Enter/Tab sesuai setting.

⚡ < 1 detik•30 HP bisa bareng

*HP cukup buka halaman scanner (/scan.html) via browser — tidak perlu install dari Play Store.

FAQ

Pertanyaan yang sering masuk.

Tidak butuh internet. Cukup laptop dan HP tersambung ke jaringan lokal yang sama (WiFi toko/kantor atau LAN). Buka dashboard via https://<IP-laptop>:3443 dari browser HP, pairing sekali, langsung bisa scan.

Hampir semua HP berkamera — Android lama maupun iPhone — selama punya browser modern (Chrome/Safari) dan bisa akses halaman /scan.html. Tidak perlu install aplikasi tambahan dari Play Store. HP kentang pun bisa, asal kameranya masih fokus.

Hingga ±30 HP bersamaan dalam satu sesi. Setiap HP terdaftar dengan nama perangkat dan kode sesi 6 digit + join key sendiri, jadi cocok untuk kasir + gudang yang scan bareng saat stok opname atau jam ramai.

Ya. Semua lewat server HTTPS lokal (port 3443) dengan sertifikat TLS self-signed + aturan Windows Defender Firewall. Hasil scan tidak pernah keluar ke internet — tetap di jaringan toko Anda. Browser akan menampilkan peringatan sertifikat saat pertama buka; itu wajar untuk server lokal, pilih Lanjutkan.

Semua aplikasi yang menerima ketikan keyboard: Excel, Notepad, Google Sheets (desktop), dan software POS/kasir Windows. ScanKilat meniru keyboard (keyboard emulation) lengkap dengan akhiran Enter / Tab / tanpa akhiran + bunyi beep tiap scan sukses.
